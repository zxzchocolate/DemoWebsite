# Xox

Xox is a lightweight daily dashboard for Android 8.1+.

## Dashboard features

- Weather lookup using the free Open-Meteo geocoding and forecast APIs. Enter a city; no API key is required.
- Local notes saved on-device with Android SharedPreferences.
- Minimal typography, bold section headings, and no emoji.
- No Accessibility Service, screen-reading, volume-key interception, or microphone access.

## Default assistant

Xox includes a minimal Android VoiceInteractionService for compatible phones. Select it in **Settings → Apps → Default apps → Digital assistant app** if MIUI exposes the option. The dashboard is also available by opening Xox from the app drawer.

## Build

Open GitHub Actions and download the `Xox-debug-apk` artifact from the latest successful **Build Xox APK** run.
